# Bruno collection

Esta colección permite probar el endpoint de conversión local.

1. Inicia la aplicación con `EXCHANGE_RATE_API_KEY` configurada.
2. Abre la carpeta `bruno` en Bruno y selecciona el entorno `local`.
3. Ejecuta **Convert currency**.

El endpoint es `POST http://localhost:8080/api/conversion`. La API key del proveedor se configura en la aplicación y no debe incluirse en esta colección.
